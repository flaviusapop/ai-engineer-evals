An agent can fail because it never finds a fact, because it finds but misuses it, or because an old belief survives after the world changes. These are different capabilities. Measure them separately before deciding whether to change search, memory, or reasoning. For the basic distinction between active context, retrieval and persistent memory, see [[context-memory-and-retrieval-foundations]].

## Separate evidence access from evidence use

Compare the ordinary workflow with a condition in which relevant evidence is supplied directly. If answers improve, investigate access: query formulation, search results and harness behavior can all contribute. This contrast does not uniquely attribute the gap to the retriever, nor is supplied evidence a mathematical upper bound or necessarily a deployable method. A reported comparison lacked a complete decomposition of those factors. [cite:fZH97QHHYjY:c04]

Inspect the trace in both conditions: Was the right information found? Did the agent recognize it as relevant? Did it use it in the decisive inference? In a selected security-task demonstration, agents discovered much of the needed information without making the final logical connection; more retrieval alone would not necessarily fix that transition. A memory oracle can likewise provide the correct memory without forcing correct use. The demonstrations do not quantify how often each downstream failure occurs. [cite:O-CBZ3JtRvo:c08] [cite:R3-anFK1YM8:c07]

## Probe context position, delayed turns and external memory

To test **in-window** use, hold the question fixed and move a task-critical passage among positions in the supplied material. Where appropriate, include conflicting documents and check reporting-period alignment. A capacity test accepting a very long input does not establish that a small but decisive financial footnote will be used. [cite:YvQ4BVTWfHI:c03]

For conversational retention, preload a realistic prefix and score a subsequent response that depends on an earlier detail. One team used ten turns followed by an eleventh test; this was a setup, not a session-length limit. Another demonstration planted a learning preference, inserted filler and asked a later relevant question. Such a probe does not require a user simulator and tests a narrow fact-recovery capability, not overall tutoring quality. [cite:esY99nYXxR4:c06] [cite:WP3hjUXd918:c10]

For **external-memory** retrieval, deliberately place the decisive fact outside the active window and verify that the harness does not leave a copy in the prompt. Compare memory disabled, candidate recall policies and directly supplied evidence. One reported example placed the fact around step 124 and the question around step 500; the exact window and full construction were not specified. A large advertised window is not itself evidence of effective recall; one cited long-context curve was disputed, so do not turn it into a universal compaction threshold. [cite:R3-anFK1YM8:c05] [cite:uIiA6DquRiE:c02]

## Measure the search trajectory and its context

An agent may inspect results, revise a query and search again. Score the final information task and record queries, results, evidence opened and the cost of the complete loop. A one-shot ranking score is still useful for diagnosis, but does not by itself estimate success after adaptation. Conversely, a fixed-query, open-loop comparison and an agent-loop comparison answer different questions: the latter includes the agent's response to results, and a difference between them is not an isolated retriever effect. Literal matches can make refinement inspectable for identifiers, but do not establish lexical superiority on every corpus. [cite:fZH97QHHYjY:c03] [cite:fZH97QHHYjY:c02] [cite:fZH97QHHYjY:c06]

Along the trajectory, compare files, lines or symbols read with labeled relevant context. **Precision** is the fraction of retrieved context labeled relevant; **recall** is the fraction of labeled relevant context retrieved. In a vendor-reported set of 50 tasks, semantic search with windowed reads achieved approximately 87% file precision versus 65% for the baseline, while broader default exploration had higher file recall. The labels may penalize alternative valid context, and the benchmark did not directly measure completed task success. Use both measures alongside outcomes rather than choosing the higher precision alone. [cite:zKk7sDMGDEQ:c01] [cite:zKk7sDMGDEQ:c03]

## Test what memory preserves and how it changes

Specify what is written, selected, ranked, recalled and retained between sessions. Test whether important facts survive intervening tasks and whether irrelevant or obsolete material crowds them out. A proposed game-agent design caches events above a salience threshold; that is a policy to test, not evidence that its threshold or long-term consistency is optimal. [cite:R3-anFK1YM8:c09] [cite:x4e5O9zN0TE:c02]

Also inject an incorrect memory as a controlled test and measure whether it is corrected, whether the error recurs and what the update costs. In one selected Pokémon example, five raw-memory runs repeated a trapdoor failure after a wrong location was stored; the speaker reported a correction with offline consolidation. The anecdote does not establish a general net benefit or a complete comparative rate. Evaluate correction quality, downstream task reward and additional compute in the intended setting. [cite:9QebvrrY3KY:c07] [cite:9QebvrrY3KY:c10]

Retaining the topic is not enough. Ask the agent to recall who supplied a claim, whether it was firsthand or a rumor, and whether later plans respect its uncertainty. A rumor repeated as a verified fact, or a known fact ignored in a plan, is a distinct failure from forgetting the words. Separating episodes from current beliefs and retaining provenance are proposed remedies, not proven guarantees. [cite:x4e5O9zN0TE:c03] [cite:x4e5O9zN0TE:c11]

## Design sequences that require learning

A sequence is not a learning benchmark merely because tasks occur in order. Provide new information the agent cannot already solve through offline familiarity, recurring structure that can transfer to later instances, and realistic feedback such as errors or textual corrections. For example, related database questions can reveal reusable schema information before a later question tests its application. [cite:iqloyWCGYQQ:c02] [cite:iqloyWCGYQQ:c03] [cite:iqloyWCGYQQ:c04]

Compare reward on later instances with state retained against a reset-between-instances baseline. The difference estimates the benefit of the allowed state mechanism within that design; report absolute reward and cost too. A large gain from a low baseline is not the same as high task quality, and the contrast is not an unrestricted causal claim about all learning mechanisms. For controls and interpretation, see [[comparing-agents-without-confounding-the-result]]. [cite:iqloyWCGYQQ:c05]

Then change part of the environment—for example, rename a database column while leaving other relationships valid. Check whether the agent preserves useful experience while discarding stale assumptions. Stability can fail even without drift: in one narrated sales forecast, feedback that a prediction was too high, then too low, led the agent back to the already-rejected high prediction. This single trace illustrates oscillation, not its prevalence. The complementary plasticity test asks whether new, relevant evidence changes behavior rather than merely being stored. [cite:iqloyWCGYQQ:c08] [cite:iqloyWCGYQQ:c10] [cite:iqloyWCGYQQ:c11]
